# 数据脱敏工具

> **免责声明**：本项目仅供学习与个人/团队内部自用。仓库内全部样例数据为虚构。文档中出现的「顺丰」等字样仅为物流业务场景举例，**不表示与任何公司存在合作、授权或官方关系**。作者不对使用本工具处理真实数据的合规后果负责——请自行遵守所在地隐私与数据安全法规。

纯本地、零网络的中文数据脱敏单页工具。双击 `脱敏工具.html` 即可使用（也可本地静态服务打开）。

## 推荐：Private 仓库

| 选项 | 建议 |
|---|---|
| **Private** | 默认推荐。即使只有虚构样例，也可避免业务文档被搜索引擎收录、减少误读。 |
| **Public** | 可以，但必须保留本页免责声明；禁止提交映射表与真实业务文件；Issues 勿贴真数据截图。 |

## 两种脱敏方式

| 方式 | 输出 | 还原 | 适用 |
|---|---|---|---|
| **对照表代号** | `【姓名·青岚】` 等无数字代号 | 需要映射表 JSON | 给 AI 分析、跨文件统一假名 |
| **通用密文** | `【密·姓名·…】` 自包含密文 | 只需同一口令，**无需对照表** | 不想保管映射表、口令可收回 |

口令仅保存在浏览器内存，不会写入映射表或导出文件。口令丢失则通用密文无法还原。

## 快速开始

1. 打开 `脱敏工具.html`
2. （可选）设置 → 导入 `顺丰规则配置.json` 体验物流向规则
3. 表格页拖入 `测试_运单明细.xlsx`，或文本页拖入 `测试_路由轨迹.txt`
4. 对照表模式：导出脱敏文件后**单独保存**映射表；通用密文模式：记牢口令

更完整的自测步骤见 `系统测试清单.txt`。

## 主要能力

- 表格（xlsx / xls / csv）与文本脱敏，支持拖放
- AI 结论回灌还原（对照表 / 口令密文）
- 自定义正则（可带上下文词）、敏感词表、白名单、跳过列
- 列类型识别（姓名、手机、身份证、运单号、工号、车牌等）

## 仓库里有什么 / 不该有什么

**可以提交**

- `脱敏工具.html`（主程序，已内联 SheetJS）
- 文档与虚构测试样例（`测试_*`、`系统测试清单.txt`）
- `NOTICE` / `LICENSE` / 规则配置样例

**禁止提交**（`.gitignore` 已覆盖常见情况）

- `*_映射表.json` 及任何含真实原值的对照文件
- 真实业务表、生产导出、脱敏报告、对照视图
- 口令、`.env`、内网地址

推送前请执行：`git status`，确认没有漏网的映射表或 xlsx 真数据。

## 其他发布建议

1. **首次推送用 Private**，需要分享时再改为 Public 或加协作者。
2. **不要用 Git LFS 传真实数据包**；样例 xlsx 保持很小即可。
3. **Release 只打包工具**：`脱敏工具.html` + `NOTICE` + `LICENSE` + README，勿带映射表。
4. **分支保护**（若多人协作）：禁止直推 `main`，PR 需有人看一眼有无敏感文件。
5. **截图打码**：README/Issue 截图不要出现真名真号；用仓库内虚构样例截图。
6. **第三方许可**：SheetJS 为 Apache-2.0，分发时保留 `NOTICE`。
7. **断网验收**：发布说明里写明「应用本身零联网」；用户可用 F12 Network 自证。
8. **口令与映射表分流**：对外演示优先用「通用密文」或纯虚构对照表，避免习惯性上传 mapping。
